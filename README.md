## What I actually do

Most enterprise AI work stalls between the demo and production. That gap is mostly not a model problem — it's evaluation, guardrails, ownership, UAT, security sign-off and cost control. That's the part I run.

```
Use-case → Build → Eval → Guardrails → HITL → Observability → Cost limits → Production
```

I sit between business, engineering, architecture, data, security and governance, and I'm technical enough to argue about the graph schema, not just the timeline.
